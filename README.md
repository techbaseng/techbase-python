## About

Python is one of the world's most popular and beginner-friendly programming languages. It is used in data science, web development, automation, artificial intelligence, and much more. In this course you will go from writing your very first line of code all the way to building real programs that solve everyday problems — 10 lessons, zero prerequisites.
